# SQL-витрина покупателей маркетплейса изделий ручной работы

Учебный проект PostgreSQL: SQL для загрузки внешних источников и инкрементального обновления витрины покупателей.

## Аналитическая задача

Собрать показатели покупателя за отчётный месяц: расходы, доход платформы, количество и среднюю стоимость заказов, медианное время выполнения, статусы заказов, популярную категорию и мастера.

## Реализация

В SQL используются CTE, JOIN, условные агрегаты, `PERCENTILE_CONT`, `RANK`, `ROW_NUMBER`, INSERT/UPDATE и таблица дат загрузки для выделения изменившихся данных.

## Структура

- [scripts](scripts) — первая версия DDL и SQL.
- [scripts_2](scripts_2) — альтернативная версия загрузки.
- В каждой папке есть создание витрины, таблицы дат загрузки, временного источника и SQL преобразований.

Папки отличаются; окончательная версия не выбрана до проверки на данных. Полные исходные таблицы DWH и demo-набор в репозиторий не включены.

## Ограничения, которые нужно проверить

- Ключ месячной витрины и UPDATE должны учитывать покупателя и отчётный период.
- Обновление по одному customer_id может затронуть несколько месяцев.
- Для популярной категории/мастера нужно проверить расчёт в пределах месяца и разрешение равных рангов.
- Строки дельты не должны размножать факты при JOIN.
- Единообразие квалификации схем и повторное применение инкремента требуют проверки.

## Запуск

Нужны PostgreSQL, исходный DWH, согласованная версия scripts/scripts_2 и порядок DDL → загрузка источника → обновление витрины.
Воспроизводимый автономный пример и контрольные ожидаемые результаты пока не подготовлены.

Проект выполнен в рамках учебной программы.
